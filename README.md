# 好医生学习辅助脚本：CME 继续教育与全员培训

本仓库包含两份**独立安装、用途不同**的油猴脚本。无需构建，不依赖题库或第三方答题服务；登录、身份核验、学分申请由你在对应网站上完成。

## 先选择适合你的脚本

| 文件 | 用途 | 当前版本 | 适用站点与入口 | 启动方式 |
| --- | --- | --- | --- | --- |
| [`cmechina.user.js`](cmechina.user.js) | CME 继续医学教育 | v0.3.1 | `cmechina.net` 及其子域名，课程目录 `course.jsp` | 右下角面板点击「开始 / 继续」 |
| [`haoyisheng.user.js`](haoyisheng.user.js) | 好医生北京全员培训 / 全员必修课 | v6.0.1 | 仅 `bjsqypx.haoyisheng.com/qypx/bj/`，课程列表 `zkbd.jsp` | 打开匹配页面后自动运行，顶部横幅可停止 |

两份脚本的匹配域名不同，可以分别安装；**不要把全员培训脚本当成所有好医生站点通用脚本**。其他地区、域名、跨域播放器或未识别页面需单独适配。

**考试通过 ≠ 观看时长达标 ≠ 已获得学分。** 两份脚本都不会自动申请学分。直接进入考试不会替你补足真实观看时间；网站提示时长不足、过程签到、验证码或身份核验时，请按网站要求处理。CME 脚本可以选择正常播放及已识别的普通过程签到；全员培训脚本没有正常播放或自动过程签到模式。

## CME 继续教育：主要功能

- 从当前已报名课程的章节目录开始，自动处理待学习、待考试章节。
- 默认尝试直接进入章节考试，也可选择正常播放或片尾尝试模式。
- 根据逐题反馈重考：保留正确答案，单选逐项尝试，多选只尝试至少两个选项的组合。
- 支持重考时题目换序，跨页面保存答案和本轮提交快照。
- 支持手动配置后续课程队列，以及用户明确启用后的自动课程评价。
- 提供开始、暂停、运行日志、进度重置和本地诊断导出。

## CME 继续教育：安装与使用

### 安装脚本

浏览器先安装并启用 **Tampermonkey（篡改猴）**，然后打开[脚本安装地址](https://raw.githubusercontent.com/masiqi/cmechina/main/cmechina.user.js)，在 Tampermonkey 安装页面确认安装。如果只是显示源码或文件下载，请使用下面的手动方式。

### 手动安装与首次启动

1. 确认 Tampermonkey 已启用，并允许它在 `cmechina.net` 上运行用户脚本。
2. 在 Tampermonkey 中新建脚本，删除默认内容，粘贴 `cmechina.user.js` 全部内容并保存。
3. 禁用原 Chrome 插件及其他同类脚本，避免重复跳转或交卷。
4. 登录好医生，打开已报名课程的**章节目录页**，地址形如 `https://www.cmechina.net/.../course.jsp?course_id=课程ID`。
5. 右下角出现「CME 学习助手」。打开设置，按需配置，保存后点击「开始 / 继续」。
6. 在正常播放或片尾尝试模式下，如果浏览器阻止自动播放，先手动点击一次视频播放，再点击「开始 / 继续」。直接考试模式不需要启动视频。

建议先只运行一门课程，核对面板日志、考试结果和章节完成状态，确认适配后再使用队列。

首次安装默认暂停。点击开始后，跨页面保留运行状态；刷新、重开页面也可能继续，请在不用时点击暂停。保持**一个学习标签页**：脚本有租约防重入，但油猴存储没有跨标签页原子锁，不能保证多个标签页同时启动时绝不冲突。

### 常用设置

展开右下角面板中的「设置与课程队列」，调整后点击「保存设置」。

| 设置 | 新安装默认值 | 使用说明 |
| --- | --- | --- |
| 学习 / 考试模式 | 直接考试 | 网站拒绝考试入口时暂停，需人工检查；其他模式见下文 |
| 正常播放倍速 | 1× | 可选 1.5×、2×，是否生效取决于播放器 |
| 自动过程签到 | 开启 | 仅点击已识别的签到控件，不处理验证码或身份核验 |
| 试卷提交上限 | 100 次 | 范围 1–100；达到上限后暂停，不无限交卷 |
| 自动课程评价 | 关闭 | 必须主动勾选确认，才会在全部章节完成后填写、提交 |
| 评价选项原文 / value | 非常满意 | 必须与真实评价页面选项匹配，不按分值猜测 |
| 评价文字 | 留空 | 按你的真实意见填写；如页面要求必填而留空则暂停 |
| 后续课程目录地址 | 留空 | 每行一门课程，先处理当前课程，再处理队列 |

「暂停」停止助手后续操作；「开始 / 继续」恢复处理。「重置助手进度」用于更换账号或明确重新开始，不是正常重考的必要步骤，会清除答案记忆和提交快照。

### 更新已有脚本

在 Tampermonkey 中编辑**原来的脚本**，用本仓库最新 `cmechina.user.js` 全部内容替换、保存，再刷新课程页面，按需点击「开始 / 继续」。不要同时启用新旧两份脚本。

如果正停留在未通过页，更新后可以继续使用旧版保存的提交快照。**不要先重置助手进度**；多选单项缓存会自动跳过，不需要删除所有答案重新猜。

## CME 继续教育：自动化流程

| 页面 / 阶段 | 行为 |
| --- | --- |
| 课程目录 `course.jsp` | 查找 `li.course_list` 中的 `.wxx` / `.xxz` 待处理章节，进入学习或考试 |
| 视频 `study2.jsp` / `polyv.jsp` / `cc.jsp` | 默认设置页面的 `questionIsOk=true` 后调用 `gotoExam()`；也可选片尾尝试或正常播放 |
| 考试 `exam.jsp` | 填写 `.exam_list > li` 中的单选、多选，点击 `#tjkj` 或已识别的交卷按钮 |
| 未通过 `examQuizFail.jsp` | 剔除题干中的「您的答案」，读取 `h3.dui` / `h3.cuo`，或验证 `ansList` / `error_order` / `error_ques` 与本轮提交快照；保留正确题，只修正错题后重考 |
| 通过 `examQuizPass.jsp` | 返回本课程目录处理下一章节 |
| 章节全部完成 | 按设置执行课程评价，或者直接结束当前课程；继续手动配置的下一门课程 |

答题不是 AI 推理或保证正确的题库：根据网站的逐题反馈有限重试。单选按 `A → B → C…` 穷举；多选按 `AB → AC → BC → ABC → AD → BD → ABD…` 穷举至少两个选项的组合，跳过 A、B、C 等所有单项。最多支持 12 个选项；新安装默认每份试卷最多提交 100 次，可设为 1–100。旧版保存的上限不覆盖，例如之前保存 30 次需手动提高。5 个选项的多选题有 26 种至少两个选项的组合；更多选项可能在穷举完之前达到提交上限。未知题型、答案组合耗尽或反馈不明确时暂停，不会无休止猜题。

### 重考、乱序与结果页参数

- 结果页实际把 `您的答案：A` 放在同一个 `h3` 内。读取反馈题干时先去掉该后缀、题号与题型标签，避免与考试题干不一致。
- 如题目提供明确 ID 属性、题目 ID 隐藏字段，或选项组名含 32 位题目 ID，按 ID 保存答案；否则按规范化题干保存。同题重考即使换题号，也不从头猜。没有 ID 且题干重复时仍暂停，不随意匹配。
- 每次交卷前保存**这一轮的题目排列、身份、题型、实际选择的字母和尝试次数**。结果页的 `error_order` 只对应这份已提交快照，不能套在下一轮重新排列后的题号上。
- `ansList` 用于核对本轮实际提交的答案；`error_order` 用于判断哪些题错了；如有可核对的 ID，检查 `error_ques`。参数长度、题号、ID 或页面对错标记矛盾时暂停。
- 单选与多选分开推进；正确题保持答案，多选通过点击复选框选择 / 取消多个选项，不只改变一个单选项。
- 同一失败结果刷新、暂停后继续时不会重复推进答案。旧版已有提交快照可以继续使用，无需先清空答案记忆。
- 参数名是 `ansList`，不是 `anaList`。直接修改失败结果页 URL 的参数不能可靠证明网站接受了新答案；本脚本不修改成绩参数，而是返回考试表单选择下一组答案并再次交卷。

v0.3.1 按本次要求，多选从 AB 开始，只尝试至少两个选项的组合；旧版缓存中的多选单项也会跳到下一个符合条件的组合，已有多项答案和单选进度保留。

### 视频模式

- **默认直接考试**：在视频页的页面上下文设置 `questionIsOk=true`（最后的 `k` 小写），调用网站的 `gotoExam()`。不访问播放器、不等待视频播放结束、不主动调用学习记录接口。入口未就绪时等待；调用后不重复请求；30 秒未跳转或网站提示时长不足则暂停，不强制改为听课。暂停或离开页面时恢复助手修改的标志。新模式字段默认为直接考试，旧版正常/快速设置需在升级后重新选择。
- **可选片尾尝试**：参考项目的思路是 `jumpToTime(片尾)` → 等待位置 → `updatePlayStatus(1)` → `playEnd()` → `gotoExam()`，并不是单独修改 `questionIsOk`。本脚本保留此模式；被拒绝或跳转失败后从头正常播放。
- **可选正常播放**：1×，可选 1.5× / 2×，是否允许倍速由播放器决定。
- 两种播放模式中，播放器对象存在但内部未初始化时，读取时长 / 进度的异常按「未就绪」处理，每秒重试，持续 90 秒仍不可用则暂停；可以使用可用的 HTML5 视频回退，不再因第一次 `getDuration()` 异常直接退出。
- `questionIsOk` 只是网站的页面标志，修改它不代表服务端已经接受学习记录或认可学分。网站仍可能拒绝考试入口。不构造接口请求绕过服务端时长校验，不绕过验证码、身份核验或人脸识别。
- 暂停只停止助手后续操作，**不暂停网站播放器和网站自身计时**。已交给网站处理的提交或跳转不能撤销。
- 不会自动关闭通用确认框；如果网站弹出交卷 / 评价确认框，需要你自行确认。视频页的「学习时长不足」提示，在直接考试模式下暂停，在片尾模式下做正常播放兜底。

### 课程队列

在设置中粘贴已报名课程的目录地址，每行一个。只接受**同协议、同域名、同端口**的 `course.jsp?course_id=...` 地址。先处理当前课程，再处理队列里未完成的课程；不会自行选课、购买、申请学分或提交证书。

### 自动课程评价

需要先勾选「我确认按以下设置自动填写并提交课程评价」，填写**页面上的选项原文或 value**（默认「非常满意」），以及可选评价文字，再保存设置。

只有目录里**每个章节明确标记完成**后，脚本才进入评价。不是“没有待学习标记就算完成”；章节状态不明会暂停。

脚本保守识别「课程评价 / 课程评估 / 评价课程」入口，以及包含「评价 / 满意 / 评估」且带单选、下拉或文本框的表单。按原文精确匹配选项，不根据分值猜高低。遇到不匹配的选项、必填字段或未适配复选框时暂停。

如页面结构不同，在「评价页面适配」中填写 CSS 选择器：

| 设置 | 含义 | 示例（不是本站已验证结构） |
| --- | --- | --- |
| 评价入口 | 目录中打开评价的元素 | `a.evaluate` |
| 评价表单 | 页面上的评价表单 | `form#evaluation` |
| 表单内提交按钮 | 相对于评价表单的按钮选择器 | `#submitEvaluate` |
| 提交成功标记 | 仅在成功后出现且可见的元素 | `.evaluation-success` |

评价提交后，只有发现明确成功提示或你配置的成功标记，才记为完成并进入下一课程。无成功标记会暂停，**不会自动重复提交**。手动打开评价页前，应先由脚本在已完成课程目录中进入评价阶段。

## CME 继续教育：排错与诊断

- **面板完全不出现**：确认脚本已启用、当前域名是 `cmechina.net` 或其子域；检查 Tampermonkey 是否获得站点访问权限。部分 Chrome / Tampermonkey 版本需按扩展提示开启用户脚本权限或开发者模式。查看控制台中 `[CME助手]` 日志。
- **面板出现但未启动**：首次安装要手动点开始；必须有可识别的课程 ID。
- **播放器未就绪**：检查视频是否放在跨域 iframe、播放器全局对象是否改名；当前版本不操作跨域 iframe。
- **日志显示已调用 `gotoExam()` 却没有跳转**：v0.2.0 错把标志写成 `questionIsOK`。真实页面使用 `questionIsOk`，两者是不同变量；更新到 v0.2.1 并刷新，日志应显示 `questionIsOk=true → gotoExam()`。
- **未通过页提示「结果题干与试卷不匹配」**：v0.3.0 已适配结果题干内嵌的「您的答案」，并按本轮提交快照处理错题参数。升级后可在当前结果页继续；不需要把 `ansList` 手动改为下一轮答案。
- **`Cannot read properties of undefined (reading 'duration')`**：v0.2.0 已修复助手在 CC 内部播放器未初始化时读取时长就退出的问题。更新脚本并刷新页面；直接考试模式不访问该播放器。
- **`Invalid 'X-Frame-Options' ... ALLOW-FROM`**：这是站点响应头警告，不是本脚本生成的；油猴脚本不能修正服务器响应头。
- **`[AdGuard Userscript Module] ... second time`**：该日志来自 AdGuard 的脚本，不是 `[CME助手]`；只有实际干扰页面时，才需要暂时停用该站点的 AdGuard Extra 排查，不要因此关闭所有安全防护。
- **章节状态不明 / 评价未识别**：不要把未知状态强行当完成。导出诊断，并提供相应页面脱敏后的 HTML 或截图以便适配。
- **试卷达到上限**：人工检查答案。必要时暂停、重置助手进度后再试。
- **切换账号**：先暂停并点击「重置助手进度」，避免复用上一账号的助手记忆。助手不存储账号密码，也不自动识别账号切换。

「导出诊断」仅下载本地 JSON，不上传任何内容。文件包含课程 ID 和日志，分享前请自行检查、脱敏。**不要提供 Cookie、密码、验证码或登录令牌。**

## 好医生全员培训：安装与使用

### 安装与启动

1. 安装并启用 **Tampermonkey（篡改猴）**，允许它在 `bjsqypx.haoyisheng.com` 上运行用户脚本。
2. 打开[全员培训脚本安装地址](https://raw.githubusercontent.com/masiqi/cmechina/main/haoyisheng.user.js)，在 Tampermonkey 页面确认安装；也可以新建脚本，删除默认内容，粘贴 `haoyisheng.user.js` 全部内容并保存。
3. 禁用原来的同类全员培训脚本，只保留一份启用版本。CME 脚本匹配另一个域名，不需要因此禁用。
4. 登录**北京全员培训**，手动打开已报名课程的课件列表，地址形如 `https://bjsqypx.haoyisheng.com/qypx/bj/zkbd.jsp?course_id=课程ID`。
5. 页面顶部出现 `[好医生全自动]` 状态横幅。首次打开会自动运行，选择可处理的未完成课件；考试页默认等待 1.2 秒后开始。
6. 保持一个培训标签页。此脚本没有跨标签页锁，不要多标签页同时答同一课程。

与 CME 脚本不同，全员培训脚本**没有右下角设置面板，也不需要点「开始 / 继续」首次启动**。建议先在一门课程上确认日志、判分及网站记录，不要把自动运行当成保证完成学分。

### 页面流程与答题方式

| 页面 | 脚本行为 |
| --- | --- |
| `zkbd.jsp` | 读取 `table.tables` / `table.table_checkbox` 中的课件状态，进入可处理的未完成课件 |
| `cc.jsp` | 从页面提供的内容中提取同站点 `slog.jsp` 考试中转地址；不是等待视频看完 |
| `slog.jsp` | 等待网站自己的跳转；1.5 秒后仍未跳转时尝试同站点考试入口 |
| `exam.jsp` | 按 `ques_list` 和 `ques_题目ID` 解析试卷，向网站原有 `examDo.jsp` 提交答案，根据明确的逐题反馈有限重试 |
| 考试通过 | 保存已确认答案，返回当前课程列表处理下一课件 |
| 所有课件显示已通过 | 停在列表页；观看时长、签到、学分等条件需要你在网站上核实 |

- 答案按**题目 ID + 选项文字**缓存。重新打开试卷时按当前选项值提交，支持题号或选项顺序变化；选项文字重复、题目元数据缺失等情况暂停。
- 单选逐项尝试；多选只尝试至少两个选项的组合，按选项数量由少到多尝试。五选多选有 26 种组合；最多支持 12 个选项。
- 每次考试页运行最多提交 200 轮，默认两轮之间等待 600 毫秒。组合耗尽会标记该课件失败并跳过；所有待处理课件都失败后停止，不自动清空失败记录循环重试。
- 判分以实际结果页 URL 或 `Location` 中的参数为依据。缺少逐题错题列表、错题 ID 不属于当前试卷、成绩参数矛盾时停止，不按缺失的反馈猜“全部正确”。
- 网络失败、HTTP 错误、超时或响应不明确时停止；不会因为 Fetch 结果不明，立刻再用另一种方式重复交卷。**此时先到网站核对是否已经提交或通过，再决定是否继续。**
- 不自动填验证码、处理身份核验，不申请学分，不执行课程评价，也没有跨课程队列；下一门课程需手动打开。

### 停止、继续、清除记录与升级

- **停止**：点击顶部「停止全自动」。助手取消待执行任务，中止客户端等待中的请求，并停止后续交卷；已到达服务器的请求、网站自己的跳转或播放不能撤销。
- **继续**：点击顶部「继续（刷新）」，刷新当前页面后恢复运行。停止状态保存在当前标签页的 `sessionStorage` 中，同站点刷新、跳转后仍保持；新开标签页不共享这个暂停状态。
- **清除助手记录**：在当前培训课程页打开 Tampermonkey 菜单，选择「全员培训：清除助手记录并暂停」。确认后清除当前课程失败列表及全员培训的全部答案缓存，不删除网站学习记录；再点「继续」恢复。切换账号前应清除答案缓存。
- **升级**：编辑原来的 `haoyisheng.user.js`，替换全部内容并保存，再刷新。不要同时启用旧版和新版。v6.0.1 保留有效的已确认答案；失败记录改为按课程隔离。

全员培训脚本使用本站 `localStorage` 保存答案及按课程区分的失败记录，使用 `sessionStorage` 保存当前课件和暂停状态；HTTP 与 HTTPS 的存储不共享，建议始终从同一个 HTTPS 站点进入。

## 两份脚本能否合并？

**技术上可以做成按域名分派的单一脚本，但不能直接把两个文件拼接后就保证正常运行。** 两份脚本的页面结构、启动方式、状态存储、交卷逻辑与油猴权限不同：

- CME 使用自己的右下角面板和 `GM_getValue` / `GM_setValue`，全员培训使用顶部横幅和本站存储。
- 全员培训需要 `GM_xmlhttpRequest`、`unsafeWindow` 和限定站点的 `@connect` 权限，合并后必须避免扩大另一个模块的操作范围。
- 单一入口需要严格按域名选择一个模块，并分别验证暂停、恢复、重考和缓存迁移，不能让两套逻辑同时启动。

本次按稳妥方案**保留两份独立脚本**：匹配域名互不重叠，分别安装使用即可。尚未做合并版的真实双站验证，因此不发布一个未经验证的拼接版。
